# Buffalo Wing Magnet

A Buffalo Bills–themed buffalo wing fridge magnet.

## Project Structure
- `buffalo-wing-magnet.scad` — Parametric OpenSCAD source (BOSL2)
- `Makefile` — Cross-platform STL build targets
- `models/` — Compiled `.stl` outputs
- `assets/` — Reference images, SVGs, and design assets

## Build
```bash
make buffalo-wing-magnet
```
