# Creality Cloud Contests

Submissions, parametric source files, and print documentation tailored for Creality Cloud design contests.

## Active & Past Contests

- [Bottle & Can Opener](./bottle-can-opener/entry-1-frost-bite/) — Multi-use ergonomic bottle and can opener contest.

## Guidelines

- Target slicer profiles: Creality Print / standard Klipper setups.
- Maintain clearances suited for high-speed enclosed printing.
- Export both production STL and pre-sliced 3MF plates when applicable.
