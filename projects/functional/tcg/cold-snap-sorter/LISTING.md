# Cold Snap Sorter — Modular TCG Sorting Bay & Frost Link System

Tired of messy piles and cluttered desks during pack openings and collection inventorying? The Cold Snap Sorter is a modular desktop card sorting station designed for rapid card handling and compact organization. Each low-profile bay features an integrated slanted ramp that lifts cards at a natural viewing angle while allowing them to overhang the rear wall for instant, pinch-free grabbing.

All four outer walls are kept solid and smooth, utilizing full circular top corner pegs that interlock horizontally using snap-on Frost Link brackets. Link bays side-by-side in long sorting rows, cluster them into 2x2 grids, or stack them vertically when not in use to reclaim desk space.

FEATURES

• Ergonomic Slanted Ramp: Internal floor slopes upward toward the back rim, presenting cards cleanly and keeping them easy to pick up without bending edges.
• Universal Sleeve Compatibility: Wide 70mm inner pocket accommodates raw cards, penny sleeves, and premium double-sleeved outer deck protectors without friction or corner pinching.
• Modular Frost Link System: Exterior walls remain 100% solid. Flat, low-profile Frost Links snap over adjacent corner pegs to lock bays into rigid rows, columns, or 2x2 grids.
• Vertical Stacking: Chamfered underside corner sockets seat securely over top corner pegs, allowing empty bays to nest stably in compact stacks.
• Open-Source: Full parametric OpenSCAD project files and source models available on GitHub under Cold Front Forge.

3MF PRINT PROFILES

The included .3mf file is organized into dedicated plates:

• Plate 1: Sorter Bay (Single Unit)
• Plate 2: Sorter Bay Array (Multi-Pack / 4x Bays)
• Plate 3: Frost Links Pack (4x 1x2 Single Links, 2x 2x2 Quad Links)

PRINT SETTINGS

• Orientation: Print flat on base floor. 100% support-free geometry.
• Material: PLA, PLA+, or PETG
• Layer Height: 0.20mm
• Wall Loops: 3 perimeters
• Infill: 10%–15% (Gyroid or Grid)
• Brim: None required (wide flat footprint provides excellent bed adhesion)
