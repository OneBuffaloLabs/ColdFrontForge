# Cold Snap™ TCG Collection

**Cold Snap™** is the dedicated product line by Cold Front Forge for tabletop, card game (TCG), and card grading storage, organization, and display accessories.

All models in this directory are fully 3D-printable and parametric via OpenSCAD, designed to fit standard TCG supplies (Pokémon, Magic: The Gathering, Lorcana, sports cards, toploaders, and sleeves).
